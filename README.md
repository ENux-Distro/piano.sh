# piano.sh

A program I vibecoded that makes digital pianos output acoustic pianos.

I vibecoded piano.sh, because I have a modest Kawai KDP75 piano at my home, but I want an acoustic piano as well. Unfortunately I don't have the money and the space.

So I vibecoded piano.sh in order to fix that problem. You need Carla installed via flatpak, so make sure you have that. You also need:

- A midi cable
- A PC
- Linux (it's tested on ENux)
- A piano
- SalamanderGrandPianoV2.sfz

Then git clone the repo, run make install and run piano-gui. It'll ask you for the .sfz of the piano you want, so enter that. Then you can spin the piano up, and record the midi of everything you're doing

Use this if you're poor like me and require the acoustic sound. Don't use this if you're rich and have an acoustic at home
